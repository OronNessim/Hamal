## 📖 על הפרויקט

מערכת web-app מלאה לניהול משמרות חמ"ל, פותחה מאפס עבור שולחן מרכזי מלכ"א. האפליקציה מאפשרת למפקד לנהל שיבוץ שבועי בזמן אמת, ולחיילים לצפות במשמרות שלהם מכל מקום ובכל מכשיר.

---

## ✨ פיצ'רים עיקריים

### 👮 ממשק מפקד
- 📅 **לוח שיבוץ שבועי** — שיבוץ ידני או אוטומטי לפי כללי עדיפות
- 🤖 **מילוי אוטומטי חכם** — אלגוריתם שמתחשב בתפקיד, עדיפות משמרת ומגבלות מילואים
- ↩️ **ביטול שינוי (Undo)** — עד 10 צעדים אחורה
- 🔒 **רענונים** — נעילת ימי רענון אוטומטית
- 📢 **הקשב המפקד** — שליחת הודעה לכל המשתמשים
- 💬 **צ'אט פרטי** — שיחה אישית עם כל חייל
- 📊 **סטטיסטיקות בזמן אמת** — משבצות מלאות, חסרות, מילואים חריגים
- 🖨️ **הדפסה / PDF** — ייצוא לוח משמרות נקי

### 👤 ממשק חייל
- 📋 **צפייה אישית** — רואה רק את המשמרות שלו
- 🕐 **לוח זמנים** — משימות שעתיות בזמן אמת
- 📩 **שליחת הודעות** — פנייה ישירה למפקד
- 📜 **לוח צו 8** — מעקב ימי מילואים

### ⚙️ כללי
- ☁️ **סנכרון Firebase** — כל שינוי מתעדכן לכל המשתמשים בזמן אמת
- 📱 **PWA** — ניתן להתקין כאפליקציה על הנייד
- 🌙 **מצב כהה** — עיצוב מותאם לסביבת לחימה
- 💾 **גיבוי ושחזור** — ייצוא/ייבוא נתונים כ-JSON
- 🔔 **התראות** — עדכון אוטומטי על הודעות חדשות

## 🛠️ טכנולוגיות

| טכנולוגיה | שימוש |
|---|---|
| **HTML5 / CSS3 / JavaScript** | Frontend מלא — קובץ אחד, אפס dependencies |

| **GitHub Pages** | Hosting חינמי |

## 📱 התקנה כאפליקציה

1. פתח את הקישור בדפדפן Chrome
2. לחץ על 3 הנקודות ← **Add to Home screen**
3. בחר **Install**
